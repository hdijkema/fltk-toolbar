fltk-toolbar

Useful commands. Within reach.

A small horizontal toolbar for FLTK, with ordinary buttons, separators and crisp SVG icons. Native callbacks and shortcuts keep working.

Read the documentation →Browse source ↗

C++17  ·  FLTK 1.4.5  ·  LGPL 2.1

01

Ordinary buttons

Keep FLTK callbacks, tooltips, shortcuts and toggle behavior. No command registry required.

02

SVG, ready to draw

Owned normal and disabled images, rasterized at the current display scale.

03

A small, clear layout

Horizontal placement, separators and a layout call after width or visibility changes.

A few lines.
A useful starting point.

The toolbar owns registered heap buttons. SvgButton also works on its own, outside a toolbar.

fltk-toolbar / usageC++17
#include <fltk_toolbar.h>
#include <fltk_toolbar_svg.h>

auto* toolbar = new fltk_toolbar::Toolbar(8, 8, 620, 38);
auto* run = new fltk_toolbar::SvgButton(0, 0, 38, 38);
run->svg(run_icon_svg);  // SVG markup, not a filename
run->tooltip("Run command");
run->callback(run_command, application);

toolbar->add_button(*run);
toolbar->separator();
toolbar->end();
